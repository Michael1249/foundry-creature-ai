# Scene-control placement — 0.43.10

The tactical suite now assigns each tool to the Foundry scene-control palette matching the document it operates on.

## Region Controls

- **Cover / concealment zones** configures a selected or listed Scene Region.
- **Ramps / stairs** creates or edits the ramp behavior on a Scene Region.

## Token Controls

Reaction controls, detection controls, Hide/Sneak, condition actions, ongoing spells, spell profiles, vampire states, ice-wall attacks, and **Pit: Climb / Jump** remain here. They operate on selected creatures, actor state, or combat actions. Pit Climb/Jump is deliberately a token tool: it makes the selected creature perform an available action around an already configured pit; it does not edit the pit Region.
